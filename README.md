# 🐢 TurtleMark 去水印

一个**全平台**的去水印工具：网页版、iPhone（添加到主屏幕当 App 用）、安卓（可直接下载 APK 安装）。所有处理都在设备本地完成，**图片/视频不会上传到任何服务器**。

## ✨ 功能

**图片工具**

| 功能 | 说明 |
| --- | --- |
| ✨ AI 修复 | 内置 LaMa AI 模型本地推理，涂抹水印区域后一键修复；先秒出快速修复预览，后台自动替换为 AI 结果 |
| 🟫 涂抹即马赛克 | 马赛克是「添加效果」工具：刷子划过的地方**实时变成马赛克**，橡皮擦过即可恢复原图，无需再点 AI 处理 |
| ⚡ 一键去水印 | 自动检测并去除**豆包 AI** 右下角文字水印、**Gemini** 右下角菱形水印，也可手动指定类型 |
| 🧩 AI 抠图 | 内置 U²-Net 模型自动分割主体，绿笔保留 / 红笔修正 → 下载透明 PNG，或一键把主体从画面中去除 |
| 🔍 双指缩放 | 双指捏合缩放图片、双击复位 1:1；内置双指检测，第二根手指落下自动取消首指未完成的笔画，避免误涂；缩放全程无损，还原后画质不变 |

**视频工具**

| 功能 | 说明 |
| --- | --- |
| ✂️ 裁剪 | 沿最近边缘剪掉含水印的一条，快且清晰 |
| 🟫 马赛克 | 拖动虚线框覆盖水印区域并打码，处理快 |
| ✨ 智能填充 | 逐帧处理填充水印区域（适合短视频），保留原声 |

- 📷 支持拍照 / 相册导入，JPG、PNG、WebP、MP4、MOV、WebM
- 🔄 前后对比滑块、多步撤销、画笔大小 / 马赛克块大小调节
- 📲 PWA 离线可用，可安装到桌面/主屏幕
- 🔒 100% 本地处理，隐私安全（AI 推理同样在设备内完成，不上传）

## 🚀 一键部署（推荐）

> 已预先在 GitHub 上创建好仓库 `TurtleMark`，只需一次配置。

1. 双击仓库根目录的 **`部署到github.bat`**（`deploy-to-github.bat` 是同一个脚本）
2. 脚本自动提交并推送 `dev`（完整源码）和 `main`（触发网页 + 安卓 APK 自动构建）
3. 首次推送会弹出浏览器登录 GitHub（登录一次即可）；git 走本地代理 `127.0.0.1:7897`，请确保代理已开启
4. 完成后打开仓库页面：**Settings → Pages → Build and deployment → Source 选 `GitHub Actions` → Save**（只需一次）
5. 等待 1～2 分钟，网页自动上线：`https://kimoji798.github.io/TurtleMark/`

以后每次改完代码，**双击 `部署到github.bat` 即可一键更新上线**。

## 🍎 iPhone 使用（添加到主屏幕当 App）

1. 用 **Safari** 打开网页地址（其他浏览器也可以，Safari 体验最好）
2. 点底部 **分享按钮** → 向下滑动选择 **「添加到主屏幕」**
3. 主屏幕出现「去水印」图标，点击即可全屏使用，像原生 App 一样

> 网页里也有「📲 安装应用」按钮，点它会给出对应提示。

## 🤖 安卓使用（下载 APK 安装）

**方式一：云端构建 APK（推荐，电脑上无需安装任何开发工具）**

1. 推送代码后，打开仓库 → **Actions** → 左侧 **「构建 Android APK」**
2. 点击右侧 **Run workflow** 按钮 → 等待构建完成（约 3 分钟）
3. 进入构建详情页，在页面底部 **Artifacts** 处下载 `TurtleMark-APK`
4. 把 APK 传到手机安装（需允许「安装未知来源应用」）

> 构建前记得把 `android/app/src/main/res/values/strings.xml` 里的
> `app_url` 改成你的 Pages 地址（一键部署脚本会自动更新）。

**方式二：浏览器直接安装**

安卓手机用 **Chrome / Edge** 打开网页 → 菜单 → **「安装应用」/「添加到主屏幕」**。

**方式三：本地构建**

用 Android Studio 打开 `android/` 目录，或运行：

```bash
cd android
gradlew assembleDebug    # Windows 用 gradlew.bat
```

产物在 `android/app/build/outputs/apk/debug/`。

## 📖 使用说明

**图片去水印 / 加效果**

1. 选择图片或拍照
2. 选工具：🖌 涂抹 / 🧽 橡皮 / ▭ 框选标记水印（画笔大小可调，支持撤销、清除）
3. 选择处理方式：
   - ✨ **AI 修复**：点「✨ AI 去水印」自动填充去除，拖动滑块对比效果
   - 🟫 **马赛克**：涂抹的地方实时变成马赛克，橡皮擦掉即恢复原图
   - ⚡ **一键去水印**：自动检测豆包 AI / Gemini 水印并去除
   - 🧩 **抠图**：绿笔标记要保留的主体、红笔标记要去除的部分 → 「💾 下载透明图」或「🗑 移除主体」
4. 下载或分享结果

> 💡 双指捏合可放大/缩小图片，双击恢复 1:1；放大后涂抹更精细。

**视频去水印**

1. 选择视频或拍摄
2. 拖动虚线框覆盖水印（拖中间移动、拖四角缩放）
3. 选择方式：✂️ 裁剪（快且清晰）/ 🟫 马赛克（快）/ ✨ 智能填充（逐帧处理，适合短视频）
4. 点「🎬 开始处理」，等待视频播放完毕（会保留原声）
5. 下载或分享结果

## 🛠 技术实现

- **纯前端**：无服务器、无后端，静态托管即可
- **AI 修复**：内置 LaMa（int8 量化）修复模型 + `onnxruntime-web` WASM 本地推理；推理在 Web Worker 中运行，界面全程不卡顿；先以 Telea 快速修复秒出预览，AI 完成后在原水印区域软边合成替换
- **AI 抠图**：内置 U²-Net（`u2netp`）分割模型（同样在 Web Worker 中推理），实时生成前景遮罩，支持绿笔保留 / 红笔去除的交互式修正
- **一键去水印**：四角连通域 + 对比度/饱和度分析定位豆包 AI / Gemini 水印，自动生成遮罩后走 AI 修复去除
- **马赛克**：涂抹时直接对画布区块做像素块化，橡皮恢复原图，所见即所得
- **模型加速下载**：模型拆分为 8 个分片，自动在多个镜像（jsDelivr / fastly / gcore / ghfast / 站内）中并发探测并选择最快源，8 路并行 + Range 分块 + 无进展自动切换源，显示百分比/速度/剩余时间进度条，并缓存到 Cache API 离线复用
- **双指缩放**：Pointer Events 多指追踪，第二指落下取消首指未完成笔画、双指结束后防误涂；缩放锚点基于页面坐标，滚动/移动页面后依然稳定不漂移；CSS transform 缩放，原始画布不重采样，缩回 1:1 画质无损
- **视频处理**：`canvas.captureStream()` + `MediaRecorder` 逐帧处理并重新编码，音频通过 Web Audio 保留
- **PWA**：Web App Manifest + Service Worker，支持离线与安装
- **安卓 App**：原生 WebView 壳工程，含文件选择、结果保存到系统「下载」目录的桥接
- **CI/CD**：GitHub Actions 自动部署 Pages + 自动构建 APK

## ⚠️ 使用须知

- 请仅对**自己拥有版权或已获授权**的内容进行去水印处理
- AI 模型首次使用会显示下载进度条，自动在多个镜像中选最快源并行加速（通常几十秒到几分钟），单个源无进展会自动切换，下载后缓存、离线复用；AI 推理在后台 Worker 中运行，界面不卡顿，单次修复通常需 1–3 分钟，期间会先显示快速修复结果
- 涂抹/框选尽量贴合水印轮廓，AI 修复效果更好
- iOS Safari 的视频输出为 MP4，安卓 Chrome 输出为 WebM（部分手机相册可能不识别 WebM，可用裁剪/马赛克模式再试或转码）

## ❓ 常见问题

- **AI 模型下载慢？** 已使用多镜像（jsDelivr / fastly / gcore / ghfast / 站内）+ 8 路并行下载，自动选最快源、无进展自动切换；若你的网络访问这些源都慢，可尝试打开代理或更换网络后重新打开页面。
- **AI 修复一直显示加载？** 模型下载完成后即可离线复用；请保持页面在前台，切到后台可能被系统暂停。
- **双指缩放时误涂？** 已内置双指检测：第二根手指落下会自动取消首指未完成的笔画，双指抬起后也不会立刻涂抹；如仍遇到问题请更新到最新版本。
- **推送失败 / 连不上 GitHub？** 确认本地代理已开启（脚本使用 `127.0.0.1:7897`）；如提示仓库不存在，请到 GitHub 确认已创建名为 `TurtleMark` 的仓库。
- **APK 提示无法安装？** 需要在手机设置里允许当前来源（浏览器/文件管理器）安装应用；首次安装可能还需关闭 Play Protect 的阻止提示。
- **视频处理没有声音？** 少数旧版浏览器不支持录制音频，会降级为无声处理，建议升级 Chrome / Safari。
